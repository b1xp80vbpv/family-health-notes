# 卵巢储备之AMH

> 更新时间：2026-09-17 (UTC+8)

**·AHM·**

。

。

。

。

评估卵巢储备功能有很多指标，比如促卵泡生成素，雌二醇，超声下窦卵泡计数等，今天我们来聊一聊AMH。

。

。

。

。

       AMH全称抗缪勒氏管激素，它是由卵巢内窦前卵泡和小窦卵泡分泌的一种糖蛋白，其水平与卵巢内卵泡数量有直接关系，可准确了解原始卵泡的库存量。成年女性随着年龄递增，卵泡储备会逐渐下降，AMH随之降低，至绝经后AMH无法检测。

      与卵泡刺激素、促黄体生成素相比，AMH波动小，加之AMH与窦卵泡数量、年龄有直接关系，因此近年来，临床上开始使用AMH评估卵巢功能。

。                 。

。                。                  。

**检查优势**

AMH不随月经周期及昼夜节律的变化，可在任何时间抽血检查。

AMH可更早更准确的反映卵巢储备功能，反映卵巢内窦卵泡数量。

一般来说年纪越大，AMH值越低。

AMH低于正常参考值，提示卵巢储备功能下降；

AMH高于正常值的2-3倍，提示可能由多囊卵巢综合征所导致；

AMH的正常值介于2-6.8ng/ml之间，大于6.8时，考虑有多囊卵巢症候群的体质。

检测AMH值可作为评估卵巢功能的辅助手段，建议AMH较低的女性同胞们，采取更积极的助孕手段以达到妊娠目的。
