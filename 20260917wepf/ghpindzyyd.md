# 双侧输卵管梗阻，先别急着做试管

> 更新时间：2026-09-17 (UTC+8)

**官方微信平台，点击上方欢迎订阅**

**输卵管**连接子宫与卵巢，是精子和卵子结合的场所，是成功妊娠的重要器官。

**输卵管的病变**主要包括：输卵管梗阻、输卵管积水、输卵管伞端微小病变等。

输卵管病变主要通过**输卵管造影**来检查，但并不是诊断的金标准。

双侧输卵管梗阻，是辅助生育技术（试管婴儿）的指征。

但是：真性的输卵管梗阻并不多见，很大一部分患者是由于其他病变导致的假性梗阻。这部分患者是不需要做试管婴儿的。

**病例一**

刘女士，31岁，已生育两娃，做过一次人工流产手术，计划生育三胎，备孕2年都没有成功。2023年1月做输卵管造影检查：提示双侧输卵管完全性梗阻。当地医生建议刘女士直接行试管婴儿。刘女士了解到整个试管婴儿过程的高经济成本、高时间成本以及低成功率的时候，她犹豫了。

思量再三后，刘女士来到了广州市妇女儿童医疗中心找到范佳颖主任，了解病情及患者的担心和焦虑后，范主任建议可以先行宫腔镜联合腹腔镜诊治，进行输卵管插管的手术，获得自然妊娠的机会。刘女士接受了范主任的建议，于2023年3月手术治疗，术中找到了双侧输卵管梗阻的原因，宫腔镜下发现双侧输卵管口均由一枚小息肉，恰巧阻塞了双侧输卵管。**经手术治疗后，双侧输卵管通常。**

**病例二**

31岁的洪女士婚后从2015年开始备孕，2016年10月行输卵管造影及输卵管介入疏通术，输卵管介入疏通失败，为双侧输卵管峡部梗阻，医生也建议试管婴儿治疗。备孕了2年多，辗转了多家医院就诊都没有任何结果，得到的是一次次的失望，本应有完美人生，却陷入了困境。2017年12月，洪女士经过一位朋友介绍，找到广州市妇女儿童医疗中心生殖内分泌专科范佳颖主任。范主任经过充分的评估后于2017年12月范佳颖主任为洪女士行宫腔镜联合腹腔镜手术，术中发现盆腔广泛粘连，盆底散在、多发子宫内膜异位病灶，直肠子宫陷凹消失。经困难的盆腔粘连分解术，恢复盆腔解剖结构后，**术中输卵管通液双侧输卵管通畅。**术后综合治疗后，术后2月自然妊娠。2018年12月14日顺产一女宝宝。

**输卵管疾病导致真性梗阻的原因**

1. 结节性输卵管炎

2. 输卵管闭锁行纤维化

3. 输卵管绝育术

4. 因手术导致的输卵管管腔重度粘连、纤维化

5. 输卵管部分切除

**输卵管假性梗阻的原因**

1. 输卵管管腔痉挛

2. 输卵管管腔粘液栓

3. 盆腔病变导致输卵管外周粘连，走行改变

4. 宫腔病变导致输卵管梗阻

5. 宫颈过度松弛

**导致输卵管假性梗阻最常见的原因**

1. 子宫内膜异位症

2. 子宫角部的子宫内膜息肉

3. 子宫角部的宫腔粘连

4. 患者紧张、疼痛导致子宫收缩、输卵管管腔痉挛

5. 盆腔手术史

**宫腔镜联合腹腔镜**

**在输卵管性不孕中的作用**

1. 检查输卵管通常程度的金标准。

2. 检查输卵管伞端的微小病变。

3. 进行宫腔镜下输卵管插管，治疗输卵管梗阻。

4. 除了输卵管外，全面检查导致不孕的解剖性因素，起到诊断作用。

5. 全面解除导致不孕的解剖性因素及部分炎症免疫因素，起到治疗作用。

6. 制定术后妊娠方案。

7. 为试管婴儿创造良好的盆腔状态。
